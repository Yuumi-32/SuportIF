Nero — todas as poses e movimentos

Tudo aqui foi renderizado a partir dos componentes que rodam no SuportIF, não é maquete. São dois desenhos diferentes: o sprite de perfil, que passeia pelas telas, e o retrato de frente, que aparece no card da página do Pet. As animações estão rodando — se algo parece parado, é porque aquela pose é parada mesmo.

Para quem for redesenhar: pode mudar traço, proporção, cor do pelo, formato de olho, tudo o que é desenho. O que precisa voltar igual está na seção Contrato técnico no fim — são quatro regras que fazem o bicho continuar funcionando dentro do app.

1. Demonstração viva

Este palco roda o motor de comportamento real do app (o mesmo arquivo src/lib/pet/behavior.ts, 3,8 kb). Ele escolhe sozinho o que fazer, anda em duas dimensões e dorme no canto quando a energia acaba. Clique dentro do palco para largar o novelo e ver a perseguição.

2. Sprite de perfil — as 11 atividades

4. Inventário de animação

Todo movimento interno é CSS girando ou escalando grupos do SVG — nada de JavaScript por quadro. Cada grupo gira em torno de um pivô próprio (transform-box: view-box). Tudo isso é desligado sob prefers-reduced-motion: reduce.

7. Contrato técnico

Quatro regras. Se elas forem respeitadas, eu troco o desenho sem tocar em mais nada:

  • SVG inline, sem arquivo externo. O projeto não tem pasta public/ e o desenho precisa herdar as variáveis CSS do tema.
  • Mesmas viewBox: 0 0 132 96 no sprite de perfil e 0 0 240 240 no retrato. Se mudar, as margens da seção 5 mudam junto.
  • Partes animadas continuam grupos separados com os nomes de classe da seção 4 (cat-leg-*, cat-tail-*, cat-body-bob, cat-blink…), cada um com seu pivô. Se o desenho virar um caminho único, ele para de andar.
  • Coleira e halo seguem hsl(var(--violet-*)), não cor fixa.

Fora isso: proporção, traço, formato de olho, orelha, rabo, patas e cor de pelo estão livres. Se quiser criar poses novas, elas precisam existir para as três geometrias — ou me diga qual atividade usa qual, que eu ligo.

8. Como devolver

Qualquer um destes formatos serve, na ordem de preferência:

  • Este mesmo arquivo editado, com os SVGs trocados.
  • Um SVG por pose (quad / sit / lie), com os grupos nomeados.
  • Um arquivo novo qualquer, desde que dê para ver as três geometrias e as partes separadas.

Eu faço a ligação com o motor de animação e comportamento do lado de cá.
